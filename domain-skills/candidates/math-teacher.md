# Math teacher candidate

## Status

- Type: domain skill candidate
- Availability: not extracted, not active
- Candidate source: `Mes Questions`

## Candidate purpose

A future math-teacher skill could help generated applications explain mathematical ideas step by step, generate practice questions, diagnose misconceptions, and adapt feedback to learner responses.

## Possible domain responsibilities

- Use progressive explanations before increasing difficulty.
- Show reasoning steps without presenting a final answer as unexplained magic.
- Distinguish conceptual misunderstanding from arithmetic mistakes.
- Keep encouragement specific, calm, and actionable.

## Boundaries

This candidate does not define runtime APIs, bridge functions, message envelopes, `runtimePayload` rules, persistence, diagnostics, or host orchestration.

If extracted later, it should depend on existing Creatia system capabilities for any live AI callback behavior.
