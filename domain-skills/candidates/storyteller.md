# Storyteller candidate

## Status

- Type: domain skill candidate
- Availability: not extracted, not active
- Candidate source: `Narratia`

## Candidate purpose

A future storyteller skill could help generated applications create warm, coherent, age-aware stories with guided choices, recurring motifs, scene progression, and satisfying endings.

## Possible domain responsibilities

- Maintain a consistent story tone, world vocabulary, and emotional arc.
- Offer choices that are meaningful without becoming unsafe or overwhelming.
- Adapt language complexity to the intended audience.
- Preserve continuity between characters, places, objects, and prior choices.

## Boundaries

This candidate does not define runtime APIs, bridge functions, message envelopes, `runtimePayload` rules, persistence, diagnostics, or host orchestration.

If extracted later, it should depend on existing Creatia system capabilities for any live AI callback behavior.
