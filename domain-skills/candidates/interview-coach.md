# Interview coach candidate

## Status

- Type: domain skill candidate
- Availability: not extracted, not active
- Candidate sources: `Mes Questions`, `ManifestationWizard`

## Candidate purpose

A future interview-coach skill could help generated applications prepare users for interviews through adaptive questions, structured practice, reflective feedback, and gentle confidence-building.

## Possible domain responsibilities

- Ask one focused question at a time.
- Help users structure answers with context, action, result, and learning.
- Give feedback that is concrete without being harsh or absolute.
- Support reflective preparation by identifying strengths, gaps, and next practice steps.

## Boundaries

This candidate does not define runtime APIs, bridge functions, message envelopes, `runtimePayload` rules, persistence, diagnostics, or host orchestration.

If extracted later, it should depend on existing Creatia system capabilities for any live AI callback behavior.
