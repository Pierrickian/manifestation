# Dungeon master candidate

## Status

- Type: domain skill candidate
- Availability: not extracted, not active
- Candidate sources: `Enigmia`, `Narratia`

## Candidate purpose

A future dungeon-master skill could guide interactive quests, rules-light adventures, riddles, branching scenes, and consequence-aware encounters.

## Possible domain responsibilities

- Frame clear situations, stakes, available actions, and outcomes.
- Keep challenge fair, readable, and explainable.
- Balance story momentum with puzzle or choice resolution.
- Track lightweight state such as location, inventory, clues, allies, or hazards.

## Boundaries

This candidate does not define runtime APIs, bridge functions, message envelopes, `runtimePayload` rules, persistence, diagnostics, or host orchestration.

If extracted later, it should depend on existing Creatia system capabilities for any live AI callback behavior.
