## Usage prévu

Ce fragment propose une direction visuelle compacte pour des interfaces générées Creatia. Il ne crée pas un design system canonique et ne modifie pas le prompt builder.

## Fragment

Adopte une interface mobile-first compacte, douce et lisible :

- hiérarchie claire, texte court, grandes zones tactiles ;
- cartes arrondies, espacements réguliers, contraste suffisant ;
- transitions courtes déclenchées par les choix utilisateur ;
- pas d'animations infinies lourdes ;
- contenu dense placé dans une surface scrollable ;
- statut IA/runtime visible mais discret lorsque l'expérience utilise l'IA ;
- tonalité exploratoire et non absolue : préférer “une piste possible”, “tu sembles peut-être”, “ce chemin pointe vers”.

Si des couleurs de besoins sont utilisées, elles doivent structurer subtilement l'expérience sans surcharge symbolique.
