## Statut

- Type : prompt-fragment
- Version : v0.1.0
- Canonicalité : non canonique
- Intégration : non branché au prompt builder

## Usage prévu

Proposer une direction visuelle compacte pour des interfaces générées Creatia.

## Fragment

Adopte une interface mobile-first compacte, douce et lisible :

- hiérarchie claire, texte court, grandes zones tactiles ;
- surfaces sombres ou calmes, cartes arrondies et contraste suffisant ;
- espacements réguliers, densité raisonnable et contenu long dans une surface scrollable ;
- transitions courtes déclenchées par les choix utilisateur ;
- pas d'animations infinies lourdes ;
- statut IA/runtime visible mais discret si l'expérience utilise l'IA ;
- tonalité exploratoire et non absolue : préférer “une piste possible”, “tu sembles peut-être”, “ce chemin pointe vers”.

Si des couleurs de besoins sont utilisées, elles structurent subtilement l'expérience sans surcharge symbolique.
